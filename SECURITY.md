# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 0.1.x | Yes |

## Reporting a problem

Please report security problems privately, not in public issues.

Use GitHub private vulnerability reporting:
<https://github.com/Antech-greyhat/PhoneScanner/security/advisories/new>

Tell us what the problem is, how to reproduce it, and what it affects. We will
reply as soon as we can. Please do not share the problem in public until a fix
is out.
